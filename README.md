# Nuskhe — Ayurveda Home Remedies (Desktop App)

A pure Python desktop application (no browser, no server) for browsing
traditional Ayurvedic home remedies — built with Tkinter, Python's
built-in GUI toolkit.

## Features
- Search by symptom
- Browse by category (6 categories, color-coded)
- "What's in your kitchen?" — filter remedies by ingredients you have
- Favorites, saved locally in a SQLite database
- 24 traditional home remedies with method, timing, and caution notes

## Requirements
- Python 3.8+ (Tkinter is included with most standard Python installs)

## How to run
```
python nuskhe_desktop.py
```

The database file `nuskhe_desktop.db` is created automatically next to
the script on first run.
